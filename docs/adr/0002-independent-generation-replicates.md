# Generate three separate synthetic datasets

On 29 October 2026, Kausthuba chose three independently generated synthetic datasets instead of reusing one frozen dataset across the three seeds. This accepts additional generation work to include variation between generation runs in the experiment; it supersedes the specification's single-corpus design. Kausthuba subsequently confirmed three complete experimental repetitions identified by seeds 13, 42 and 7: each has separate zero-shot, few-shot and AugGPT generation, C2–C5b use their own repetition's synthetic data, and C5b paraphrases that repetition's exact C5a source examples. The held-out real test set remains fixed and the result grid remains 36 rows; this decision alone does not establish statistical independence or authorize regeneration of frozen data.
